# 1. 연구 개요

## 1.1 연구 목표

Mixture-of-Experts(MoE) 추론 비용을 각 라우팅된 토큰에 맞게 전문가(expert) 연산량을
적응시켜 절감한다.

전문가에 고정된 하나의 연산 예산을 할당하는 대신, FERRET은 전문가가 실제로 얼마나
실행되어야 하는지를 예측한다.

목표는 모델 품질을 유지하면서 FLOPs(연산량)를 줄이는 것이다.

## 1.2 핵심 가설

라우팅된 토큰마다 필요한 전문가 충실도(fidelity)가 다르다.

따라서

> 정적(static) 전문가 연산 → 토큰 적응형(token-adaptive) 연산

으로 전환하면 품질-연산량 트레이드오프를 더 좋게 달성할 수 있어야 한다.

## 1.3 핵심 아이디어

각 전문가는 하나의 **중첩(nested) 저랭크(low-rank) 분해**로 표현된다.

원래 가중치:

```
W ≈ U Σ V^T
```

최대 랭크(rank) 분해만 저장한다. 런타임에는 이 분해의 **일부(prefix)**만 실행한다.

**예시** — 랭크 64로 저장된 경우

- 토큰 A → 랭크 16 실행
- 토큰 B → 랭크 64 실행
- 토큰 C → 랭크 32 실행

즉, 랭크 8 / 16 / 32 / 64를 각각 독립적으로 저장하지 않는다.
