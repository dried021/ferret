4. 이번 세션에서 겪은 함정 (똑같이 겪지 않도록)
===============================================================================

- **flash_attn 캐시 오염**: ~/.cache/huggingface/hub/.../modeling_deepseek.py
  blob이 조용히 패치 안 된 원본으로 되돌아가 있을 수 있음(원인 불명, 오늘
  실제로 발생). `if is_flash_attn_2_available():` 블록이 있으면(→ try/except
  ImportError로) 패치 안 돼 있는 것 — ImportError: flash_attn not found 로
  실패하면 이걸 의심할 것.
- **merge_eval은 GPU 1장으로 절대 돌리지 말 것** — 31GB 모델이 24GB 1장에
  안 들어가 CPU/disk offload가 걸리고, 이 경로가 에러 없이 NaN을 만든 전례
  있음(local_gpu_driver.sh 주석 참고).
- **PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True 필수** — 없으면 5번째
  언어(Bengali) eval에서 아주 근소한 차이(1.6GB 필요, 1.5GB 여유)로 OOM남.
- **GPU3은 공유 helper GPU** — local_gpu_driver.sh(다른 조건 백필용 드라이버)
  가 GPU0/1에서 돌 때 merge_eval 단계에서 GPU3을 빌려씀. `flock
  /tmp/phase1_merge_eval.lock`을 반드시 같이 걸어서 직렬화할 것 — 안 그러면
  실제로 다른 작업의 merge_eval을 OOM으로 13번 실패시킨 전례 있음(오늘).
  GPU 작업 시작 전에 항상 `nvidia-smi` + `ps -eo pid,cmd | grep local_gpu_driver`
  로 다른 세션이 뭘 쓰고 있는지 먼저 확인할 것.
- 백그라운드 bash job은 cwd가 안 이어질 수 있음 — 로그 경로는 항상 절대경로로.
