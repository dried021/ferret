# 5. 실험 로드맵 (Experimental Roadmap)

## Exp0 — 전문가 압축 가능성 (Expert Compressibility)

**목표**: 전문가(expert)가 저랭크로 정확하게 표현될 수 있는가?

**산출물**
- 재구성 오차 (reconstruction error)
- 다운스트림 성능 저하 (downstream degradation)

---

## Exp1 — 오라클 랭크 생성 (Oracle Rank Generation)

라우팅된 모든 토큰에 대해 오라클 랭크를 생성한다.

**분석 항목**
- 토큰 분포 (token distribution)
- 레이어 분포 (layer distribution)
- 전문가 분포 (expert distribution)

---

## Exp2 — 정적 베이스라인 (Static Baselines)

- Rank 8
- Rank 16
- Rank 32
- Rank 64

**측정**: 품질 대비 연산량 (quality vs compute)

---

## Exp3 — Oracle Dynamic Rank

**비교**: 최선의 Static Rank vs Oracle Dynamic Rank (동일 평균 FLOPs 조건)

이 실험이 **핵심 Go / No-Go 실험**이다.

---

## Exp4 — 라우터 임계값 베이스라인 (Router Threshold Baseline)

단순한 매핑: `router margin → rank`

오라클과의 상관관계를 측정한다.

---

## Exp5 — 학습된 랭크 예측기 (Learned Rank Predictor)

**입력**
- layer (레이어)
- expert (전문가)
- router statistics (라우터 통계)
- hidden statistics (은닉 상태 통계)

**출력**: 필요 랭크 (required rank)

**비교 대상**: Static / Router Threshold / ML Predictor / Oracle
