# 2. 런타임 파이프라인

추론 시 데이터는 다음 순서로 흐른다.

```
입력 토큰 (Input Token)
   ↓
라우터 (Router)
   ↓
라우팅 특징 (Routing Features)
   - layer id (레이어 ID)
   - expert id (전문가 ID)
   - router score (라우터 점수)
   - router margin (라우터 마진)
   - router entropy (라우터 엔트로피)
   - hidden statistics (은닉 상태 통계)
   ↓
랭크 예측기 (Rank Predictor)
   ↓
필요 랭크 (Required Rank)
   ↓
Prefix 분해 실행 (Prefix Decomposition Execution)
   ↓
MoE 출력 (MoE Output)
```

핵심은 라우터가 산출하는 정보(점수, 마진, 엔트로피 등)와 은닉 상태 통계를 특징으로
사용하여, 랭크 예측기가 해당 토큰에 필요한 랭크를 결정하고, 저장된 최대 랭크 분해
중 그 앞부분(prefix)만 실행한다는 점이다.
