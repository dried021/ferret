# 12. FERRET Toy 실험 로드맵 (실행 순서)

Toy 실험들의 목적은 최종 예측기(predictor)를 만드는 것이 **아니다**.

목표는 연구 가설을 **단계별로 검증**하는 것이다. 각 실험은 다음 실험을 진행할
근거(justification)를 제공해야 한다.

---

## Toy 0. 전문가 압축 가능성 (Expert Compressibility)

**질문**

각 전문가(expert)가 저랭크 분해(low-rank decomposition)로 잘 표현될 수 있는가?

**절차**

1. MoE 레이어 하나를 선택한다.
2. 모든 전문가를 분해한다.
3. 다음 랭크들을 평가한다.
   - 8
   - 16
   - 32
   - 64
4. 원본 전문가와 비교한다.

**지표**

- 재구성 오차 (reconstruction error)
- 전문가 출력 거리 (expert output distance)
- 다운스트림 손실 (downstream loss)

**Go 조건**

중간 정도의 랭크에서도 품질이 합리적으로 보존된다.

그렇지 않으면 → 중단(stop).

## Toy 1. 토큰 랭크 이질성 (Token Rank Heterogeneity)

**질문**

서로 다른 라우팅된 토큰들은 서로 다른 랭크를 필요로 하는가?

**절차**

라우팅된 모든 토큰에 대해:

- 후보 랭크를 모두 평가한다.
- `oracle_rank(token)`을 생성한다.

**분석**

- 히스토그램 (histogram)
- 레이어 분포 (layer distribution)
- 전문가 분포 (expert distribution)

**지표**

- 오라클 랭크 히스토그램
- 분산 (variance)
- 엔트로피 (entropy)

**Go 조건**

오라클 랭크가 하나의 값에 집중되어 있지 않다.

## Toy 2. Oracle Dynamic vs Static

**질문**

동적 랭크(dynamic rank)가 실제로 유용한가?

**절차**

다음을 비교한다.

```
Static Rank 8, Static Rank 16, Static Rank 32, Static Rank 64
```

vs

```
Oracle Dynamic Rank
```

**동일한 평균 FLOPs** 조건에서 비교한다.

**지표**

- perplexity (퍼플렉시티)
- 다운스트림 정확도
- FLOPs
- Pareto 곡선

**Go 조건**

오라클(Oracle)이 최선의 정적(static) 방식을 능가한다.

**이 실험이 가장 중요한 실험이다.**

## Toy 3. 어떤 특징이 오라클 랭크를 설명하는가?

**질문**

라우팅 시점(routing-time) 정보로 오라클 랭크를 설명할 수 있는가?

**절차**

오라클 랭크와 다음 항목들 사이의 상관관계를 측정한다.

- router score (라우터 점수)
- router margin (라우터 마진)
- router entropy (라우터 엔트로피)
- top1 probability (top1 확률)
- top2 probability (top2 확률)
- layer id (레이어 ID)
- expert id (전문가 ID)
- hidden norm (은닉 상태 norm)

**지표**

- Pearson (피어슨 상관계수)
- Spearman (스피어만 상관계수)
- Mutual information (상호 정보량)
- AUROC (이진 분할 기준)

**산출물**

특징 중요도 순위 (feature importance ranking)

## Toy 4. 단순 임계값 베이스라인 (Simple Threshold Baseline)

**질문**

사람이 직접 설계한 규칙(hand-crafted rule)으로 오라클의 이득을 회복할 수 있는가?

**절차**

예시:

```
마진(margin)이 크다 -> 낮은 랭크
마진(margin)이 작다 -> 높은 랭크
```

임계값(threshold)을 스윕(sweep)한다.

**지표**

- 품질
- FLOPs
- 오라클 일치도 (oracle agreement)

**산출물**

강력한 휴리스틱 베이스라인 (strong heuristic baseline)

## Toy 5. 학습된 예측기 (Learned Predictor)

**질문**

경량(lightweight) 예측기가 오라클 랭크를 추정할 수 있는가?

**입력**

- layer (레이어)
- expert (전문가)
- router statistics (라우터 통계)
- hidden statistics (은닉 상태 통계)

**출력**

랭크 클래스 (rank class)

**비교 대상**

Static / Threshold / ML Predictor / Oracle

## Toy 6. 런타임 실행 가능성 (Runtime Feasibility)

**질문**

예측된 랭크들이 효율적으로 실행될 수 있는가?

**절차**

토큰들을 `(expert, rank)` 기준으로 그룹화한다.

**측정**

- 버킷(bucket) 분포
- 평균 버킷 크기
- 이론적 지연시간(latency)
- 실제 지연시간 (선택 사항)
