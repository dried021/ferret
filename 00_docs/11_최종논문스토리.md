# 11. 최종 논문 서사 (Final Paper Story)

## 관찰 (Observation)

서로 다른 라우팅된 토큰들은 서로 다른 연산량을 필요로 한다.

## 가설 (Hypothesis)

정적(static) 전문가 연산은 FLOPs를 낭비한다.

## 방법 (Method)

각 전문가를 중첩(nested) 저랭크 분해로 표현하고, 라우팅 시점 특징으로부터 최소로
필요한 실행 랭크를 예측한다.

## 검증 (Validation)

다음을 보인다.

```
Oracle Dynamic Rank > Best Static Rank
```

그다음, 경량 예측기(lightweight predictor)가 오라클(Oracle)에 근사함을 입증한다.

## 결론

이를 통해 **동적 전문가 충실도(dynamic expert fidelity)**를 Mixture-of-Experts
추론을 위한 새로운 연산 할당(computation allocation) 메커니즘으로 확립한다.
