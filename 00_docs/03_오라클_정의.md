# 3. Oracle(오라클) 정의

라우팅된 모든 토큰에 대해 다음을 평가한다.

```
Rank 8, Rank 16, Rank 32, Rank 64, …
```

**Oracle Rank(오라클 랭크)** = 미리 정의된 품질 기준을 만족하는 가장 작은 랭크.

## 가능한 품질 기준

- 은닉 상태 재구성 오차 (hidden reconstruction)
- 전문가 출력 거리 (expert output distance)
- 다운스트림 NLL (negative log-likelihood)
- 정답 성능 저하 (answer degradation)

Oracle Rank는 지도학습(supervision)의 레이블로 사용된다.
