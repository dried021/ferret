# 6. 평가 방법 (Evaluation)

## 품질 (Quality)

- perplexity (퍼플렉시티)
- downstream accuracy (다운스트림 정확도)
- output distance (출력 거리)

## 효율 (Efficiency)

- average executed rank (평균 실행 랭크)
- theoretical FLOPs (이론적 FLOPs)
- parameter memory (파라미터 메모리)
- runtime latency (런타임 지연시간, 선택 사항)

## 예측 (Prediction)

- rank accuracy (랭크 정확도)
- oracle agreement (오라클 일치도)
- mean absolute rank error (평균 절대 랭크 오차)
