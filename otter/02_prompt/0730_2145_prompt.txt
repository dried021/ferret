===============================================================================

(직전 버전과 내용 동일 — 안 바뀜. 요약만 반복.)

D²-MoE는 shared base + expert-specific delta(Fisher-weighted merge /
activation-aware SVD whitening / structured pruning)로 구성된 training-free
MoE 압축 방법이다. 이 프로젝트는 calibration corpus의 "언어 구성"이 이
압축 절차와 압축 후 다국어 성능에 미치는 영향을 체계적으로 검증한다.

**연구 공백**: Transfer gap(dense PTQ에서는 이미 보고됨) / **Localization
gap(이 논문의 핵심 novelty — D²-MoE 파이프라인 단계별 원인 규명)** /
Cross-validation gap(forward-only proxy vs 진짜 gradient Fisher) /
Prescription gap(§6에서 시도했으나 negative result).

**본 연구의 기여 요약**(갱신):
1) D²-MoE 기반 training-free MoE compression에서 calibration language 영향을
   체계적으로 평가한 최초의 다국어 분석 — 5개 언어(EN/KO/ZH/Swahili/
   Bengali) + Balanced, 전부 3 seed 완주(§4.1, **100% 완료**).
2) EN-only/target-language/multilingual calibration을 동일 token budget
   아래 비교, worst-language robustness 분석(§4.2 취약도-비례, §6 Table 4
   worst-language 비교).
3) routing coverage(§5.2, 완료), Fisher importance(§5.1, 완료), **whitening
   basis rotation(§5.3, 신규 완료)**, structured pruning 민감도(§4.3, 완료
   — korean_only 범위)로 calibration 언어와 압축 후 성능의 관계를 단계별로

쉽다. within은 "같은 calibration 조건, 다른 calibration seed"(3개 seed

최종 성능)의 잡음 하한선이라는 점을 논문에서 명시할 것.

**추가(§3.17 XNLI v2 방법론)**: base model(instruction-tuning 없음)에는
자연문 true/false/neither continuation 채점이 lettered MC보다 적합하다는
발견 자체가 방법론적으로 보고할 가치가 있다 — Limitations 또는 Appendix에
"lettered MC 프롬프트가 base model에서 실패하는 구체 사례"로 짧게 기록하는
것을 고려(다른 연구자가 같은 함정에 빠지는 것을 막는 재현성 기여).
